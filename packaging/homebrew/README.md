# Homebrew

Tap: **[github.com/sagwaco/homebrew-tap](https://github.com/sagwaco/homebrew-tap)**

```bash
brew install sagwaco/tap/plz
```

Or install directly from this repository:

```bash
brew install ./packaging/homebrew/plz.rb
```

Upgrade with `brew upgrade plz`, `plz update`, or `plz configure update`
(auto-detects Homebrew installs).

See [docs/release.md](../docs/release.md) for the per-release checklist and
[docs/homebrew-tap-agent-prompt.md](../docs/homebrew-tap-agent-prompt.md) for
one-time tap setup.
